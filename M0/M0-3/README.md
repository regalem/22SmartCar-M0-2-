## 1. 脚本原本意图

1. 读取 `sensor_data.csv`（列：`time`、`value`）
2. 计算 `value` 的平均值、标准差
3. 剔除离群值（`|value - mean| > 2 * std`，同时剔除偏大和偏小）
4. 把清洗后的数据保存为 `cleaned_data.csv`（内容为 `time,value`）
5. 打印统计摘要

原始脚本跑不通，即使修到能跑，结果也是错的。经排查共定位 **8 处缺陷**。

## 2. 缺陷清单（现象 / 原因 / 修复）

| # | 位置（原脚本） | 现象 | 原因（原理） | 修复 |
| :-: | :-- | :-- | :-- | :-- |
| 1 | 第 37 行 `float(row["Value"])` | 运行即 `KeyError: 'Value'` | CSV 表头是小写 `value`，字典取键**大小写敏感**，`"Value"` 取不到 | 改为 `row["value"]` |
| 2 | 第 50–53 行 标准差 | `std = -0.0000`，明显不合理 | 累加的是偏差 `(v-mean)` 而非**偏差平方** `(v-mean)**2`，且最后**没有开方**。由定义 `sum(v-mean) == 0`，故结果恒为 0 | 累加 `(v-mean)**2`，除以 `n` 后 `math.sqrt`，得总体标准差 |
| 3 | 第 57 行 离群值判据 | 偏小离群值 `-21.3` 被保留 | 判据只有 `v > mean + 2*std`，只砍上界、漏下界，也没用**绝对值** | 改为 `abs(v - mean) <= 2*std` 保留，一次判定同时覆盖上下界 |
| 4 | 第 56–58 行 删除逻辑 | 遍历会跳元素、`remove` 删错元素 | `for v in data` 的同时 `data.remove(v)`，**边遍历边改列表**；且 `remove` 删的是第一个相等值而非当前元素 | 改为遍历 `zip(times, data)` 构造新列表，不破坏原列表 |
| 5 | 第 28、65 行 `cleaned` | 打印"剩余 0 条"、输出为空 | `cleaned` 声明后**从未 append**，清洗结果没被收集 | 过滤时同步收集 `cleaned / cleaned_times` |
| 6 | 第 61 行 输出路径 | 读取成功后抛 `FileNotFoundError: '/out\cleaned_data.csv'` | `os.path.join("/", "out", ...)` 拼出**根目录绝对路径**，`/out` 目录不存在；也不符合"默认写当前目录" | 直接用相对路径 `cleaned_data.csv`（落在当前工作目录） |
| 7 | 第 62–66 行 写文件 | CSV 只有 `value` 一列、且行间多空行 | `writer.writerow([v])` 只写一列、丢了 `time`；`open` 未用 `newline=""`，`csv` 的 `\r\n` 又被文本模式转换一次产生空行；文件也没有关闭 | `with open(path, "w", newline="")`，按 `(time, value)` 两列写出 |
| 8 | 全局流程（无入口/无校验） | 硬编码文件名，无法按契约用 `--input/--output`；异常输入直接抛栈回溯 | 全程模块级全局变量 + 顶层流程，**没有参数解析、没有输入校验、没有异常捕获** | 拆出函数 + `argparse`，逐项校验并统一捕获，出错打印可读信息、退出码 2，不出现 `Traceback` |

> 说明：把 #2 的平方与开方看成一件事（"标准差公式"），把 #7 的丢列、
> 空行、未关闭看成同一处"写文件"缺陷，正好是题目所说的 **8 处**。

### 2.1 为什么"修复顺序存在依赖"

题目的难点不在单点，而在缺陷会互相掩盖：

- **不修 #1**，脚本连数据都读不进来，后面的问题根本暴露不出来。
- **不修 #2**，`std` 恒为 0，离群值判据 `> mean + 2*std` 永远不成立——#3、#4 会被完全掩盖。
- **不修 #3/#4**，#5（`cleaned` 为空）也看不出来，因为列表本来就空。
- **不修 #6**，即使前面都对了，也写不出文件。

所以必须按 "先让它跑起来 → 再看结果对不对 → 最后补健壮性" 的顺序推进，
这也正是本项目每个缺陷一次 commit 的思路。

## 3. 修复后的脚本

入口文件仍为 `sensor_analyzer.py`，拆分为 `load_data / mean_and_std /
remove_outliers / write_cleaned / main` 五个函数。

### 3.1 运行方式（接口契约）

```bash
# 方式一（推荐，显式指定输入输出）
python3 sensor_analyzer.py --input sensor_data.csv --output cleaned_data.csv

# 方式二（无参数，默认读写当前目录下的 sensor_data.csv / cleaned_data.csv）
python3 sensor_analyzer.py
```

两种方式都支持。`cleaned_data.csv` **默认写在当前工作目录**，不含任何写死的绝对路径。

### 3.2 输出契约

stdout 中保证包含：

```text
均值 mean = 50.4315
标准差 std = 18.5033
```

（同时打印读取条数、剔除条数、剩余条数、输出路径。）

### 3.3 边界处理

| 异常输入 | 行为 |
| :-- | :-- |
| 文件不存在 | 打印 `错误: 输入文件不存在: ...`，退出码 2 |
| 空文件 | 打印 `错误: 输入文件为空: ...`，退出码 2 |
| 只有表头、无数据行 | 打印 `错误: 输入文件没有数据行: ...`，退出码 2 |
| 缺列（无 `time`/`value`） | 打印缺失列与实际表头，退出码 2 |
| 非数值内容 | 打印出错行号与内容，退出码 2 |
| 字段不足（某列为空） | 按非数值处理，退出码 2 |

以上均**不出现 `Traceback`**，符合"异常输入不得裸崩"的要求。

## 4. 验收证据

### 4.1 正常运行

对给定的 `sensor_data.csv`（60 条）运行：

```text

剔除离群值 3 条
均值 mean = 50.4315
标准差 std = 18.5033

```

剔除的三条离群值为 `118.4`、`132.7`（偏大）和 `-21.3`（偏小），
说明上下界都被正确处理。`cleaned_data.csv` 为 1 行表头 + 57 行数据。

用一份**不复用被修脚本任何函数**的独立实现（`sum`/`math.sqrt`/`abs` 手工计算）比对：

produced  kept = 57

均值、标准差、清洗结果**完全一致**。
